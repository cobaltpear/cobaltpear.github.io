Make a pack for your worker

A pack is one small file, pack.json, that tells Cobalt Pear how to call your RunPod Serverless worker. You need a working endpoint first — the pack only says what to send it. Fill in the boxes and the file is made below.

1. What your worker takes

2. Name it

3. Where things go

Found by itself where it could — change any that are wrong. Only Prompt is needed.

4. Your pack.json










5. Put it in your repo and try it


    

  1. Save it as pack.json at the top of your worker's GitHub repo, on the main branch.
    2. 

  2. Open Cobalt Pear → Models → Custom → paste the repo's address under «Your own worker» → Add. No repo? Choose a pack or ComfyUI workflow takes the file itself.
    3. 

  3. Paste your endpoint ID and send a prompt. The app reads the pack again each time it opens, so a fix shows at once.
    4. 




6. Let people find it


Add the topic cobalt-pear to your repo (the ⚙️ next to About on its GitHub page). Every worker with a pack is listed at github.com/topics/cobalt-pear.
