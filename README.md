# Cobalt Pear

Type a prompt, get the result — from your own RunPod Serverless endpoints, straight from the browser.

- **Cobalt Pear** (free): https://cobaltpear.github.io/
- **Demo** (fake RunPod, nothing is billed): https://cobaltpear.github.io/demo/

Your RunPod key, prompts and pictures go only from your browser to RunPod. Models, endpoint IDs and results stay in your browser. Cobalt Pear records nothing about you.
