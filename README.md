# Cobalt Pear

Type a prompt, get the result — from your own RunPod Serverless endpoints, straight from the browser.

- **Simple** (free): https://cobaltpear.github.io/
- **Plus**: https://cobaltpear.github.io/plus.html — several models at once

Your RunPod key is never stored or sent anywhere but RunPod. Models, endpoint IDs and results stay in your browser.
